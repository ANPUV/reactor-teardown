A 6-8px square in a `mark-*` colour followed by the status word in mono. Running is the `signal` mark. "Never seen" is a hollow square (1.5px `faint` outline), so it differs by shape as well as colour. The word carries the meaning; the mark is a glance aid.

Use for health, result kinds, audit status, queue state. The word is the code's own status word (English, mono).
