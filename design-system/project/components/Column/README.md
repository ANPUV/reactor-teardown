A column is a `well` box with a 1px `line-soft` border, an 8px identity square (`id-1` to `id-6` by the column's POSITION, cycling after six; a reference shelf takes `faint` and a dashed border and does not use a position), the name in `card-title`, the count in mono `muted`.

A card is `ground` with a 1px `line` border and 14px padding: a mono meta row (chips, dates) with a hairline under it, the title in `card-title`, a 4px `ink` progress bar on a `line-soft` track, and counts in mono 11px `muted`. Colour by position, not by status id, because lists are renameable and reorderable.
