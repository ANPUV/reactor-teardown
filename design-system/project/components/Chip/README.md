A square mono chip (`chip`: 11px, 600, padding 2px 6px). Neutral is `wash` with `chip-ink`; a state is its own ground and ink (`ok-bg`/`ok-ink`, `warn-bg`/`warn-ink`, `danger-bg`/`danger-ink`) with an optional 1px line.

A chip that carries a state also carries a 7px mark and its word: `mark-ok` and `mark-warn` fail 3:1 alone. A running state uses the `signal` mark. Dates, counts and ids are neutral chips.
