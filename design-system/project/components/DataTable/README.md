Header cells are mono 11px uppercase `muted` with a 1px `line` under; rows have 1px `line-soft` rules; ids, times, codes and numbers are mono and tabular, numbers right-aligned. A status cell is a mark and a word. The selected row is `well` with a 2px `ink` left rule (every row reserves the 2px, transparent, so text does not shift).

Wide tables scroll inside their own `overflow-x: auto` box; the page never scrolls sideways. Every number that opens something stays the underlined link it is.
